## Cognitive load failures
- **Redundancy.** In every zero-row state the header note and the empty line say the same thing:
  - disconnected: "Not connected" / "Not connected."
  - auth_required: "Sign-in expired" / "Sign-in expired."
  - syncing_first: "Syncing first mail · 0 cached" / "Syncing first mail… 0 cached." (a ticking count shown twice)
  - sync_error: "Sync failed · no network · 0 cached" / "Sync failed: The network is unavailable."
  - not_configured: "Gmail not configured" / "Gmail is not configured on this device."
- **Mixed phrasing for one cause.** "no network" in the header vs "The network is unavailable" in the empty line and drawer.
- **Drawer repetition.** The failed-sync drawer shows "Sync / Failed" and then "Sync failed: …". The auth_required drawer says "Sign-in expired" three times.
- **Header density.** At 1030 with the read-only hint, Preview tag and Unread chip, the header holds "Inbox 18", "Unread only", "Preview · in-memory", "Gmail is read-only Review access" and four glyphs.
- **Misleading drawer facts.**
  - A disconnected account shows "Gmail · read-only" and "Sync: Idle".
  - "Never synced" appears beside "18 cached" (a fixture artifact, but it is what renders).

## Priority issues

**[P1] The tab floor does not protect two tabs plus the Unread chip at 1030 px.**
- Why: with a saved split, "Unread only" and the read-only hint, the Inbox tab renders at width 13 px with its label at width 0. Only "18" and "N… 15" show. "Unread only" ends at x=259 and the Preview tag starts at x=262, so they touch. The primary single-tab case is fine.
- Fix: the floor should be computed (tabs plus chip) or the hint should collapse to its link text. Alternatively, cap the saved tab label at about 12ch.
- Command: `/impeccable layout`.

**[P2] The header note and the empty line duplicate each other in every zero-row state.**
- Why: this is the same fact at 12px twice, 40px apart, and it breaks the "one action, one place" intent. Action duplication is fixed; wording duplication is not.
- Fix: when the empty line carries the sentence, drop the header note's text and leave only the Preview tag. Or make the empty line carry only what the header doesn't (the hint, plus the action).
- Command: `/impeccable distill`.

**[P2] The first-run void is only half addressed.**
- Why: the right column is a blank 272px, and the list is one sentence. In auth_required, syncing_first, sync_error and connected with zero rows, the contact pane still reads "No correspondent information is available." beside an empty list.
- Fix: suppress that line when the list has no rows. Add one more concrete line to the empty state, such as what read-only means or the first-sync duration.
- Command: `/impeccable onboard`.

**[P3] Label inconsistency across surfaces.**
- Why: Connect Gmail, Connect, Sign in and Sign in again name the same action. The destructive confirm button is visually a muted ghost with no danger tint.
- Fix: unify on "Connect Gmail" and "Sign in again". Give the confirm button a `--danger` text or border.
- Command: `/impeccable clarify`.

**[P3] Drawer facts are wrong for the state.**
- Why: a disconnected drawer says "Gmail · read-only" and "Idle". A failed state shows "Sync / Failed" with a redundant "Sync failed:" line beneath it.
- Fix: hide the mode and sync rows when disconnected. In the error state, show only the error line.
- Command: `/impeccable clarify`.
