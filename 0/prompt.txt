Issues, in priority order:

1. P1 R reply shortcut opens the composer but focus never reaches the body. DraftEditorCore.vue takeFocus (~164-171) only takes focus from <body> or a <button>, while the R handler (App.vue ~1988) fires from any non-editable, non-button target. Scenario: click the message text (focus lands on the article[tabindex=-1], or on a Details <summary>, or a .participant span), press R: composer opens, focus stays on the article, and typed text is swallowed by the key handler (App.vue ~1885). Fix: make the hand-off robust (accept focus inside the reader / any non-editable element in takeFocus, or have prepareReply focus the body explicitly after mount). Add component tests that press R from the article, a summary and a participant span, and assert the body textarea is document.activeElement; also cover the IME path (isComposing) and discard-flow focus return (after discarding, focus returns somewhere sensible in the reader). Existing tests (reply-shortcut.component.test.ts ~54-81) only start from a toggle.

2. P2 Spoofable recipient. DraftEditorCore.vue ~114-115, ~221: while To equals the sender mailbox, the row shows only the display name and the address is in a hover title. A sender named "Bank Support" can hide x@evil.test. Show the real address visibly (next to the name, e.g. name + <address> in the Ash/secondary colour) in the compact To row; keep it compact. 3. P2 Local-only caveats ("recipients not validated, no Bcc") are tooltip/sr-only only (DraftEditorCore ~92, ~206), so keyboard users never see them. 6. P3 Bidi control characters (e.g. U+202E RLO) in attachment file names render as-is (MessageAttachments.vue ~58). Strip or neutralise bidi controls from displayed names (keep the real name for the save path/title if safe). Add a test.

7. P3 Signature dimming: a bare `--` line followed by up to 12 real lines is dimmed as a signature (message-body-format.ts ~44, ~103). Tighten it (e.g. require the standard `-- ` delimiter with trailing space, or only dim when it's the last block) so real content is not dimmed. Add tests.
